    3. Dependencies

    Für das weitere Vorgehen müssen einige Pakete installiert werden:

    • System und Python aktualisieren, setuptools installieren
    • In neueren Raspberry OS Versionen müssen wir in einer virtuellen Umgebung arbeiten. Diese mit den Commands rechts erstellen und aktivieren. Wir arbeiten immer in dieser, falls sie also nach einem Neustart nicht aktiv ist, erneut mit source env/bin/activate aktivieren
    • Die Commands rechts ausführen. Dadurch wird automatisch Blinka installiert und konfiguriert.
    • Blinka testen: Mit dem Code rechts ein Testskript erstellen
    • Der nano-Editor sollte jetzt geöffnet sein
    • Den Code hineinkopieren. Mit ctrl + x, dann y, dann Enter speichern
    • Das Skript ausführen. Der Output sollte mit dem Beispiel übereinstimmen
    #Update PI
sudo apt-get update
sudo apt-get -y upgrade
sudo apt-get install -y python3-pip
sudo apt install --upgrade python3-setuptools
     
    #Virtual enviroment setup
cd ~
sudo apt install python3-venv
python3 -m venv env --system-site-packages
source env/bin/activate
     
    #Blinka installation
cd ~
pip3 install --upgrade adafruit-python-shell
wget https://raw.githubusercontent.com/adafruit/\
Raspberry-Pi-Installer-Scripts/master/raspi-blinka.py
sudo -E env PATH=$PATH python3 raspi-blinka.py
     
    #Blinka Test
source ~/env/bin/activate
cd $HOME
nano blinkatest.py
     
    #Per copy-paste einfügen
import board
import digitalio
import busio
print("Hello, blinka!")
pin = digitalio.DigitalInOut(board.D4)
print("Digital IO ok!")
i2c = busio.I2C(board.SCL, board.SDA)
print("I2C ok!")
spi = busio.SPI(board.SCLK, board.MOSI, board.MISO)
print("SPI ok!")
print("done!")
#Speichern mit Ctrl + X, dann Y, dann Enter
     
    #Test ausführen:
python3 blinkatest.py
