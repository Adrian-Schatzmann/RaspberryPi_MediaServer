    9. Plex

    Als Medienserver verwenden wir Plex:

    • Da Plex nicht im standard Repository ist, müssen wir es manuell hinzufügen
    • Plex installieren
    • Plex mit dem Command rechts testen. Das Ergebnis sollte "Active: active (running)" sein. Nach der Kontrolle mit control + c beenden
    • Das MacBook mit demselben Netzwerk verbinden, einen Browser öfnnen und eine Verbindung mit dem Server herstellen. Ggf. das Plex Abo und Login überspringen
    • Über die Ordnerfreigabe Medien auf den Plex Server laden
    • Neue Mediatheken für Filme, Musik etc. erstellen. Dabei den jeweiligen Medienordner auswählen
    • Über den Browser oder die Plex App kann jetzt auf den Server zugegriffen und die Medien abgespielt werden. Das Synchonisieren kann aber einen Moment dauern 
    #Plex Repository hinzufügen und Installation
cd ~
source env/bin/activate
sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://downloads.plex.tv/plex-keys/PlexSign.key \
| gpg --dearmor \
| sudo tee /usr/share/keyrings/plex.gpg >/dev/null
sudo chmod 0644 /usr/share/keyrings/plex.gpg
 
echo "deb [arch=$(dpkg --print-architecture) \
signed-by=/usr/share/keyrings/plex.gpg] \
https://downloads.plex.tv/repo/deb public main" \
| sudo tee /etc/apt/sources.list.d/plexmediaserver.list
     
    #Plex Installation
sudo apt update
sudo apt install -y plexmediaserver
     
    #Test (ergebnis sollte "Active: active (running)" sein)
systemctl status plexmediaserver
