    4. Netzwerk Setup

    Wir können einen Hotspot definieren, mit dem wir uns automatisch verbinden wenn verfügbar. Ansonsten gibt es ein fallback WLAN:

    • Hotspot auf dem iPhone aktivieren
    • Erneut nach verfügbaren WLAN Netzwerken suchen (Es kann einen Moment dauern, bis der Hotspot angezeigt wird. Wenn nötig commands mehrfach eingeben)
    • Hotspot und Fallback Netzwerk hinzufügen. Dabei die SSID und Passwörter anpassen. Bei Erfolg bricht die SSH Verbindung ab, daher neu verbinden
    • Die Prioritäten setzen. Eine höhere Zahl entspricht einer höheren Priorität. Konfiguration am besten durch einen Neustart des Raspberry Pi testen 
    #Wifi suchen
sudo nmcli device wifi rescan
nmcli device wifi list

    #Hinzufügen (SSH Verbindung bricht ab, jeweils neu verbinden)
sudo nmcli device wifi connect "aLabor" password "[PASSWORT]" name "aLabor"
sudo nmcli device wifi connect "[Hotspot_SSID]" password "[PASSWORT]" name "[Hotspot_SSID]"
     
    #Prioritäten setzen
sudo nmcli connection modify "aLabor" connection.autoconnect-priority 1
sudo nmcli connection modify "[HOTSPOT_SSID]" connection.autoconnect-priority 2

#Aktuelle Verbindung prüfen:
iwgetid -r
