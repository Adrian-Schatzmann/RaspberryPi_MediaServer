    4. Plex

    Als Medienserver verwenden wir Plex:

    • Da Plex nicht im standard Repository ist, müssen wir es manuell hinzufügen
    • Plex installieren
    • Plex mit dem Command rechts testen. Das Ergebnis sollte "Active: active (running)" sein
    • Das MacBook mit demselben Netzwerk verbinden, einen Browser öfnnen und eine Verbindung mit dem Server herstellen (kann einen Moment dauern)
    #Plex Repository hinzufügen und Installation
sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://downloads.plex.tv/plex-keys/PlexSign.key \
| gpg --dearmor \
| sudo tee /usr/share/keyrings/plex.gpg >/dev/null
sudo chmod 0644 /usr/share/keyrings/plex.gpg
 
echo "deb [arch=$(dpkg --print-architecture) \
signed-by=/usr/share/keyrings/plex.gpg] \
https://downloads.plex.tv/repo/deb public main" \
| sudo tee /etc/apt/sources.list.d/plexmediaserver.list
     
    #Plex Installation
sudo apt update
sudo apt install -y plexmediaserver
     
    #Test (ergebnis sollte "Active: active (running)" sein)
systemctl status plexmediaserver
     
    #Auf dem MacBook im Browser öffnen (Hostname anpassen)
