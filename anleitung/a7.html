    7. SSD

    Die SSD muss formatiert und gemountet werden. Es wird auch eine SMB Freigabe benötigt:

    • Die SSD identifizieren. Anhand der Speichergröse geht das ganz gut. Sehr wahrscheinlich ist der Name sda1
    • Die SSD formatieren und und die Mount-Konfiguration vornehmen. Für das automatische mounten nach dem Systemstart ist die Bearbeitung eines config Files nötig
    • Den Samba Server installieren und die Freigabe erstellen. Zudem müssen die Ordnerberechtigungen korrekt gesetzt werden
    • Mit einem Client im gleichen Netzwerk wie der Server die Verbindung testen
    • Ordner für die Plex Medien erstellen
    #SSD identifizieren (Name notieren, z.B. sda1)
lsblk
     
    #SSD unmounten falls gemountet (ggf. Name anpassen)
sudo umount /dev/sda1

#SSD formatieren (ggf. Name anpassen)
sudo mkfs.ext4 /dev/sda1

#Mountpoint erstellen
sudo mkdir /mnt/ssd

#UUID kopieren (ggf. Name anpassen)
sudo blkid /dev/sda1

#Datei bearbeiten um SSD automatisch zu mounten
sudo nano /etc/fstab

#Unten im Dokument einfügen (UUID anpassen)
UUID=[UUID]  /mnt/ssd  ext4  defaults,noatime  0  2
     
    #Freigabe erstellen
#Samba Server installieren
sudo apt update
sudo apt install samba samba-common-bin -y

#Samba config bearbeiten
sudo nano /etc/samba/smb.conf

#Am Ende der Datei einfügen (Benutzername anpassen)
[SSD]
   path = /mnt/ssd
   browseable = yes
   read only = no
   guest ok = no
   valid users = [NAME]

#Samba Passwort setzen (ggf. Name anpassen)
sudo smbpasswd -a adspi
sudo smbpasswd -e adspi

#Berechtigungen setzen (ggf. Name anpassen)
sudo chown -R adspi:adspi /mnt/ssd
sudo chmod -R 775 /mnt/ssd

#Samba neu starten
sudo systemctl restart smbd
sudo systemctl enable smbd
